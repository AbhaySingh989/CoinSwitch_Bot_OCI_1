================================
OCI TRADING BOT MANAGEMENT COMMANDS
================================

This document provides a quick reference for the most common shell commands
used to manage, update, and monitor the trading bots running on your OCI Docker instance.

------------------------

- Private Key Location: C:\OCI\ssh-key-2025-11-22.key

-----------------------------
2. BOT DEPLOYMENT & UPDATES
-----------------------------

# Standard procedure to update the bots with the latest code from GitHub.

# 1. Navigate to the project directory
cd ~/CoinSwitch_Bot_OCI_1

# 2. Update the specific bot code (Example: Bot 1)
cd repos/bot_1
git pull
cd ../..  # Go back to main folder

# 3. Rebuild and Restart the bots to apply changes
#    (This only restarts bots that had changes)
docker compose up -d --build

# 4. Verify they are running
docker compose ps


------------------------
3. SERVICE MANAGEMENT
------------------------

# The bots are managed using Docker Compose.
# Run these commands from: ~/CoinSwitch_Bot_OCI_1

# Check Status: See if bots are running.
docker compose ps

# Start All Bots:
docker compose up -d

# Stop All Bots (Removes containers):
docker compose down

# Stop Only One Bot (e.g., bot_1):
docker compose stop bot_1

# Restart All Bots (Soft restart):
docker compose restart

# Restart Only One Bot:
docker compose restart bot_1


----------------------
4. LOG MONITORING
----------------------

# View Logs for ALL bots (Press Ctrl+C to exit):
docker compose logs -f

# View Logs for a SPECIFIC bot (e.g., bot_1):
docker compose logs -f bot_1

# View Last 100 lines of logs:
docker compose logs --tail=100 bot_1

-------------------------
6. MONITORING CPU & MEMORY
-------------------------

# 1. Visual Task Manager (Best for overall server health)
#    - Shows CPU usage bars at the top (0-100%)
#    - Shows RAM usage bar (Mem)
#    - Press 'F10' or 'q' to exit.
htop

# 2. Docker Stats (Best for checking individual bots)
#    - Shows exactly how much CPU/RAM each bot is using.
#    - Press 'Ctrl+C' to exit.
docker stats

# 3. Check Disk Space
#    - Shows if your hard drive is full.
df -h


-------------------------
7. DATABASE QUERY (LIVE)
-------------------------

# You can query the database files directly on the host server because they are mounted.

# 1. Navigate to the bot data directory
cd ~/CoinSwitch_Bot_OCI_1/bot_data/bot_1

# 2. Open the database file
sqlite3 Crypto_Data.db

# --- Once inside the sqlite> shell ---

# 3. Set formatting
.mode column
.headers on

# 4. Show recent signals
SELECT * FROM Signals ORDER BY Signal_Timestamp DESC LIMIT 10;

# 5. Exit
.quit


------------------------------
8. DATABASE CLEANUP (DANGER)
------------------------------

# WARNING: These commands permanently delete data.

# 1. Stop the bots first
cd ~/CoinSwitch_Bot_OCI_1
docker compose stop

# 2. Delete the database file (Example: Bot 1)
rm ~/CoinSwitch_Bot_OCI_1/bot_data/bot_1/Crypto_Data.db

# 3. Restart the bots (A new empty DB will be created)
docker compose up -d
